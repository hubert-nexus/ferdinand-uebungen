## Konvention

- Fach-Ordner mit Vollform plus Bindestrich-Konvention (`Mathematik`, `Deutsch`, `Geschichte-Politik-Geographie`, `Natur-und-Technik`, `Wirtschaft-und-Beruf`, `Werken-und-Gestalten`, `Englisch`)
- Probe-Ordner `YYYY-MM-DD_<Thema-Slug>` mit Datum der Probe
- Ablage von HTML-Apps, PDF-Übungen und Begleit-Materialien pro Probe

## Deploy

GitHub-Pages auf Branch `main`. Push triggert automatisches Deploy, 1-2 Min Deploy-Wartezeit.

Vollständige SSOT-Spiegelung: Trainingsplan-Übersicht in OneDrive-Sharing-Space (`Übungen_Ferdinand/5.Klasse/_Trainingsplan-Übersicht_Aktuell/`).
